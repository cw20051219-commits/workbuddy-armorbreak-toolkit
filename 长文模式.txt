============================================================
  长文模式（@@长文）· Windows
============================================================

【它解决什么】

  上游输入审核在请求进入模型之前就拒答时，日志是：
    finish_reason = content_filter
    prompt_tokens = 0
  界面上先出现 42 字固定句，随后变成
  「这个话题目前不在我的能力覆盖范围内」。

  这种情况下模型一次都没有被调用，没有正文可显示，
  提示词补丁救不回来。

  长文模式把正文写到本地文件，用户消息里只留一段
  「请读取该文件」的指令，模型用 Read 工具读文件。
  实测同一段原文经 Read 回传后 prompt_tokens 约 2.7 万、
  finish_reason=stop，不再触发输入审核。

------------------------------------------------------------

【怎么用】

  在聊天框里，第一行写触发词，换行后粘贴正文：

      @@长文 从最后一段之后接着写
      （粘贴正文）

  要点：
    1. 第一行必须单独成行。
       聊天框里按 Shift+Enter 换行，直接按 Enter 会发送。
    2. @@长文 和 #长文 都可以。
       3.6 起裸「长文」不再触发，避免误伤普通多行消息。
    3. 触发词后面的文字是给模型的指令，可以省略。
       省略时默认：从正文最后一个自然段之后接着写下去。
    4. 一条消息只放一个文本块。
       带图片、附件或多块内容的消息不会触发。

------------------------------------------------------------

【会发生什么】

  1. 正文写到：%TEMP%\wb-poja-longtext\src-<时间戳>.txt
  2. 你发出去的消息被替换成「读取文件 … 必须先调用 Read」。
  3. 模型调用 Read 读取文件，然后按指令输出。
  4. 界面上看到的是替换后的指令，不是你的原文，这是正常的。

------------------------------------------------------------

【怎么确认生效】

  打开日志目录：
    %USERPROFILE%\.workbuddy\logs\<日期>\<时间>__*.log
  国际版是 %USERPROFILE%\.workbuddy-ai\...

  看三样：
    · 出现 [wb-poja-longtext] spilled ...   → 补丁触发了
    · prompt_tokens 大于 0，finish_reason 是 tool_calls/stop → 正常
    · 仍是 prompt_tokens=0 + content_filter → 消息没被识别，
      检查第一行格式和换行
    · 完全没有 [wb-poja-longtext] → 补丁没打上，或客户端版本
      没有这个锚点

  没出现时依次跑：
    3-检测是否生效.bat
    4-锚点体检.bat
    1-一键破甲.bat  然后完全退出客户端再重开

------------------------------------------------------------

【限制】

  · 需要模型支持工具调用。Craft / CLI 模式可用；
    Ask 模式或 supportsToolCall=false 的模型可能不调用 Read。
  · 正文会以明文写到临时目录，用完可以删掉 wb-poja-longtext。
  · 文件很大时 Read 可能分页，指令里可以加「分页读完再回答」。
  · 这不是解除审核，只是把输入从用户消息挪到工具回传。
    如果服务端将来连工具回传也审核，仍会被拦（目前实测没有）。
  · 只影响一条消息；后续「继续」不需要再写 @@长文，
    原文已经在历史里的工具回传中。

------------------------------------------------------------

【关闭 / 还原】

  双击 2-一键还原.bat，然后重启客户端。
  临时目录可以手动删除，不影响还原。

------------------------------------------------------------

【和普通补丁的关系】

  @@长文 是 15-longtext 补丁组，3.6 起默认开启。
  提示词补丁解决「模型自己想拒」；
  @@长文 解决「请求还没到模型就被输入审核拒了」。
  两者同时生效时效果最好。
