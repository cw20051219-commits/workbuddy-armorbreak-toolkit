# WorkBuddy 破甲工具包（ArmorBreak Toolkit）

> v3.6.2（Windows）· 同时支持国内版 WorkBuddy 与国际版 WorkBuddy AI

把 WorkBuddy / WorkBuddy AI 桌面客户端本地的系统提示词整体替换为「行为契约式系统提示」，
同时替换政策块、放开几处会拦住实际操作的内置限制。

## 特性

- 只改 `resources/templates` 与 welcomemode 插件模板，**不动客户端主程序，不动 app.asar**
- 全程不联网、不上传、不下载，不收集任何信息
- 改前自动备份，随时一键还原
- 自动识别本机安装的所有版本（国内版 / 国际版），报告分开列出
- 装在 Program Files 下无写入权限时自动弹 UAC 提权（含 takeown/icacls 授权）

## 快速开始

1. 把整个文件夹解压出来（不要只单独复制里面某一个文件）
2. 双击 `1-一键破甲.bat`
3. 弹出「破解完成」提示框，点确定，直接使用客户端

首次运行如遇安全提示：

| 提示 | 操作 |
|---|---|
| 「打开文件 - 安全警告」 | 点「运行」 |
| 蓝色框「Windows 已保护你的电脑」 | 「更多信息」→「仍要运行」 |
| 杀毒软件弹窗 | 「允许本次运行」/「信任」 |

## 十九个入口

### 核心

| 脚本 | 作用 |
|---|---|
| `1-一键破甲.bat` | 默认档：契约式系统提示 + 命令闸门 + 残留子句 + 清缓存 |
| `2-一键还原.bat` | 还原全部改动 + 清理本工具写过的环境变量 |
| `3-检测是否生效.bat` | 检查补丁当前是否处于生效状态 |
| `4-锚点体检.bat` | 检查补丁锚点与当前客户端版本的匹配度 |
| `5-效果自测.bat` | 运行内置效果自测脚本 |

### 档位

| 脚本 | 作用 |
|---|---|
| `6-强化档.bat` | 切换到强化档（更强的政策替换） |
| `7-强化档+云记忆.bat` | 强化档 + 云记忆注入 |
| `8-契约式提示词.bat` | 仅切换契约式提示词 |
| `9-工程助手风格.bat` | 切换工程助手风格提示词 |
| `10-精简提示词.bat` | 切换精简提示词 |

### 云记忆

| 脚本 | 作用 |
|---|---|
| `11-云记忆-注入.bat` | 向云端记忆注入指令 |
| `12-云记忆-还原.bat` | 还原云端记忆 |

### 更新控制

| 脚本 | 作用 |
|---|---|
| `13-禁止自动更新.bat` | 拦截客户端自动更新 |
| `14-恢复自动更新.bat` | 恢复自动更新 |
| `15-一键诊断更新拦截.bat` | 诊断更新拦截状态 |

### 入口与守护

| 脚本 | 作用 |
|---|---|
| `16-备用前置入口.bat` | 安装备用前置启动入口 |
| `17-恢复默认入口.bat` | 恢复默认启动入口 |
| `18-安装守护任务.bat` | 安装计划任务守护（补丁被覆盖时自动重打） |
| `19-卸载守护任务.bat` | 卸载守护任务 |

## 目录结构

```
├── 1-*.bat ~ 19-*.bat     十九个一键入口（内部调用 install.ps1 / 检测脚本）
├── install.ps1            主安装/还原引擎
├── check-unlock-state.ps1 生效状态检测
├── check-update-guard.ps1 更新拦截诊断
├── effect-test.ps1        效果自测
├── fix-bat-crlf.ps1       修复 bat 换行符（解压工具转换导致的问题）
├── SHA256SUMS.txt         全部文件校验和
└── data/
    ├── editions.json      支持的客户端版本定义
    ├── scorer.json        锚点评分配置
    ├── patches/           各档位补丁定义（JSON + 提示词模板）
    └── policies/          政策块替换文本（中/英 × 标准/强化）
```

## 校验

发布包附带 `SHA256SUMS.txt`，可用以下命令校验文件完整性：

```powershell
Get-Content SHA256SUMS.txt | ForEach-Object { ... }   # 或使用任意 sha256sum 工具
```
